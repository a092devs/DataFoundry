# DataFoundry

DataFoundry is an end-to-end data analytics project focused on transforming
raw data into meaningful business insights.

## Project Goals

- Collect and understand raw data
- Clean and transform data using Python
- Store structured data in a relational database
- Perform analytical queries using SQL
- Explore data statistically
- Build interactive dashboards
- Communicate findings through clear business insights

## Tech Stack

- Python
- Pandas
- NumPy
- SQL
- PostgreSQL
- Power BI
- Git
- GitHub
